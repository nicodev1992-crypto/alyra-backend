# Alyra Backend 🩺

Python backend for **Alyra**, a diabetes and meal-tracking application integrated with PostgreSQL.

## 🛠️ Tech Stack

* **Language:** Python 3.13
* **Database:** PostgreSQL

## 🚀 Features

* **Meal & Diabetes Tracking:** Log meals, carbohydrate intake, and blood glucose levels.
* **Database Checks:** Backend logic to verify user and record existence before inserting or updating data in PostgreSQL.
* **Data Validation:** Input checks to ensure valid health metrics before database write operations.
